## 6. 공통 작업 원칙

- 모든 작업은 AGENTS.md를 준수한다.
- 확인되지 않은 요구사항은 임의로 확정하지 않는다.
- 기존 팀원 코드는 수정하지 않는다.
- 작업 시작 전 승인된 범위를 확인한다.
- 사용자가 직접 수행 가능한 작업은 직접 진행한다.
- 작업 완료 후 실제 테스트 결과를 기록한다.
- 사용자 승인 없이 다음 작업을 임의로 진행하지 않는다.
- 비용 발생 리소스는 승인 후 생성한다.
- Git commit, push, merge는 사용자 승인 후 수행한다.
- 작업 상태는 검증 결과에 따라 갱신한다.
